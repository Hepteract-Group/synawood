# Visual proof

If a claim can be seen, show it. Do not have VO announce what the picture already is, and do not have type shout a claim the picture does not earn.

## Prefer

- 12 tabs → 1 notification
- Prompt → storyboard → finished video
- Photograph a receipt → it is already categorised

## Avoid

- “Our product saves time” over generic stock
- Invented dashboards, fake logos, fake counts
- Proof numbers not in Catalog / Extracts / Brand DNA

## Motion

Authored Remotion should *be* the demonstration (count-up from Catalog, UI chrome, before/after). Path C logo wrap is not the proof beat.

## Done when

A viewer with sound off can see the mechanism or the outcome in picture.
