# Talking-head first pass

1. `enhance_speech` if noisy (skip when already enhanced).
2. `build_cut_list` then `apply_cut_list` — fillers, long pauses, false starts. `edit_for_clarity` only if the brief is clearly violated.
3. `apply_jump_cut_zooms` on those filler and false-start ranges so jumps do not flash.
4. `captions_from_transcript` — karaoke when word timings exist; otherwise a band, and tell them. Then `set_caption_style` for sparse keyword color and licensed marks.
5. `generate_music` if missing, then `duck_music`.
6. `place_sfx` — whoosh on the hook, hit on the CTA. `apply_motion_preset` — hook_punch / cta_hit.
7. `import_product_brand` if brand chrome is missing.
8. `inspect_preview` — required. Then narrate. The why-log is the receipt.
