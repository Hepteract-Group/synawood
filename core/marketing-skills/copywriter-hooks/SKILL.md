# Copywriter hooks

## Rules

- First on-screen line earns attention in ≤3s - tension, outcome, or curiosity.
- Match platform density (TikTok/Reels denser than LinkedIn/landing).
- CTA must be one concrete verb phrase; align with `intent.cta` / brand default.
- Never invent social proof, pricing, or compliance claims.

## Tool hints

- `set_hook_title` for the open.
- `set_end_card` / scene role `cta` for the close.
- Prefer rewriting overlays over regenerating footage when budget is tight.
