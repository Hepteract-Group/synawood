# Product in scene

Brand (non-negotiable): use this project's Brand Studio — logo, primary/accent, fonts, CTA, claims. Do not invent a palette. Do not fake product UI. Path C / set_slide carries headlines; generated pixels are scenes, not typography.

## Rules

Fake UI is a reject.

- Prefer stillAssetIds / logo from Brand Studio as reference in generate_image / generate_slide_background when the tool allows refs.
- Hands, desk, phone bezel — the product is an object in a scene.
- If no stills exist, say open Brand — do not draw a pretend app.

## Tools

Use Studio Tools only. No shell, no vendor CLIs, no skills.sh scripts.
