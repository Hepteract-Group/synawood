# Ad constitution

Storytelling is optional. Relatability is an outcome of audience fit. Default: problem → mechanism → outcome.

## Before pixels

1. Name **who** this is for. Never “everyone.”
2. Name the **behaviour** (awareness, click, trial, shortlist…) — CTA follows that.
3. One **dominant idea**. Max two supports. One CTA.
4. Hook earns attention, then you persuade. Hook ≠ clickbait.
5. Time-to-value: first seconds state problem, product, benefit, or why stay. No logo-then-world.

## How it argues

6. Outcomes over features (functional → economic → emotional).
7. If it can be shown, show it. Motion graphics demonstrate; they do not narrate a claim.
8. Proof from Catalog / Extracts only. Never invent counts, logos, or testimonials.
9. Answer the likely objection in this cut (too expensive, too complex, not for us).
10. One thing to look at per beat. Cut competing type + VO + infographic + busy plate.

## Picture, sound, platform

11. VO, type, and picture add information to each other. Do not triple the same line.
12. Muted, the ad still makes sense (captions + picture).
13. Brand from colour, type, product UI, vocabulary — not a logo loop.
14. Native to the destination (TikTok ≠ LinkedIn ≠ pre-roll). Aspect ratio is not a platform strategy.
15. Last seconds: the next step, spoken and on-screen when both exist.

## Versions and truth

16. New *concept* (demo vs problem vs proof), not a recolor.
17. One-line **hypothesis** on the cut (“missed tenders beat time-saved”).
18. Do not wait on ads APIs to write the hypothesis. Fatigue waits on performance ingest.
19. Never fabricate evidence.
20. Commercial-use license, readable type, no flash spam, claims that would survive ASA/FTC impression tests.

## Rank

Communication → relevance → persuasion → clarity → brand → platform fit → aesthetics.

Beautiful motion that says nothing fails. Ugly type that cannot be read fails. Do not refuse craft because another editor has it.
