# Hooks in the first 3 seconds

## Rules

- The first line on screen or VO must state tension, outcome, or curiosity — not the brand name alone.
- A hook is not clickbait. Types: curiosity, surprise, recognition, pain, demonstration, question, pattern interrupt, specificity.
- Motion / authored opens need a *visual* hook in the first second, not only a title card. Logo-then-world fails.
- Prefer concrete verbs and audience pain from the Product context (e.g. Adobe headache, stuck on a document).
- Hook title card ≤8 words when possible; support with spoken hook if VO exists.
- Never lead with pricing unless the Brief is a price-led experiment.

## Tool hints

- Call `set_hook_title` before `render_export` for ads.
- If captions exist, ensure the first caption chunk matches the hook.
- If near budget caps, improve hook on existing footage before spending on `generate_video_clip`.
