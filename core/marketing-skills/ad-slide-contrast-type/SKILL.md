# Contrast type

Brand (non-negotiable): use this project's Brand Studio — logo, primary/accent, fonts, CTA, claims. Do not invent a palette. Do not fake product UI. Path C / set_slide carries headlines; generated pixels are scenes, not typography.

## Rules

If the scene is bright, type sits on a dark caption panel (Brand captionBg). If the scene is dark, type is paper.

- Do not paint the headline into the diffusion image.
- Check inspect/preview: if type vanishes, regenerate the background darker/lighter, do not shrink the words.
