# Stat punch

Brand (non-negotiable): use this project's Brand Studio — logo, primary/accent, fonts, CTA, claims. Do not invent a palette. Do not fake product UI. Path C / set_slide carries headlines; generated pixels are scenes, not typography.

## Rules

A giant number on a flat color is a dashboard, not an ad.

- layout: stat. Background: the human cost or payoff of that number (clock, pile of files, empty inbox).
- Do not invent stats. Use Brand DNA proof points / Catalog only.
- One number per slide.
