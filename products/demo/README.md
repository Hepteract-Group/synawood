# Demo Product context

Stub Product so Studio and the operator shell boot without a private example Product folder.

Not a marketed product. No ICP, strategy, or content pipeline.

## Boot locally

1. Create a Product in the dashboard with slug `demo` (Products → Create Product). Migrations do not insert this row.
2. Open Studio under that Product. Brand Studio → **Import product brand** loads this kit.

## Layout

```
config.ts
governance/approval-policy.json
brand-kit/   # logos, colors, voice, one placeholder still
```
