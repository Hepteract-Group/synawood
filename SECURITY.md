# Security

Report vulnerabilities privately. Do not open a public GitHub issue for a
security report.

**Email:** security@hepteract.group

Please include:

- What you found and how to reproduce it
- Impact (data exposure, spend, account takeover)
- Whether you have a fix in mind

We will acknowledge receipt and follow up. Hosted Synawood and customer
Organizations are out of scope for public
bounty programs until we say otherwise.
