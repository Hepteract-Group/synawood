# Success and kill rules

## Creative Studio track success

- Ship weekly 30–120s branded ads (talking-head **and** motion graphics) with **zero freelance editor or motion-designer hours** (marketing team, ADR-0070, ADR-0091).
- Approve time stays within the weekly content batch budget (see content Runbook).
- Final assets land in the Content pipeline without ad-hoc Dropbox/Slack file hunting.

## Kill / narrow rule

After **three** Studio-assisted weekly batches, if standard ≤60s formats still require an external editor or motion designer, **fix the product** (empower the agent — ADR-0091) or revisit hire. Do not “narrow” by stripping motion craft so ads stay slop.

## What does not count as success

- Feature count on the timeline UI with no Approved ads
- Synthetic ads that never get Approved into Final assets
- Neutering the Studio Agent so the product “doesn’t look like CapCut” ([ADR-0091](../adr/0091-empowered-agent-authored-compositions.md))
