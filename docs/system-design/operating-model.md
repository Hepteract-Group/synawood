# Operating model

## Manual first, then automate

Every process starts as a Runbook. After 2–3 manual runs, automate painful steps. The Runbook remains the documentation of what automation does.

## One-hire operability

A single marketing hire must be able to execute without tribal knowledge: Runbooks = how, dashboard = what/when, Product context = for whom.

## Phases (GTM)

| Phase | Job |
|---|---|
| 0 | Context, GTM one-pager, baselines, first runbooks |
| 1 | Funnel fix — tracking, CRO, landings. No paid spend |
| 2 | Search ads + content engine + founder cadence. Postiz adapter is Plan 29 (does not wait on ads). |
| 3 | Retargeting, optimization, day-90 kill/scale |

## Parallel Creative Studio track

Studio may proceed **alongside Phase 1** as a risk mitigator (avoid editor hire). See [ADR-0004](../adr/0004-parallel-studio-track.md). Cap maker time; do not block Phase 1 exit criteria.
