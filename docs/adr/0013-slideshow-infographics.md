# Slideshow / infographic as first-class Studio format

Creative Studio includes a dedicated **slideshow / carousel** format (`slides[]`, channel presets, dual still+MP4 export, optional VO), not only a vague “infographic recipe.” Instagram and TikTok-style posts use Remotion Path C type/logo over brand-bound backgrounds.

**Why:** Founder needs carousel/slideshow outputs as a core risk mitigator for organic social; Recipe C alone was underspecified for agents to implement.

**Rejected:** Treating carousels as “just export PNGs from chat.” Baking all text into diffusion images. Deferring the format until after CapCut-like timeline parity.
