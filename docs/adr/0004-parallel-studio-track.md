# Creative Studio runs parallel to Phase 1 as a risk track

Creative Studio development is allowed **in parallel with Phase 1** funnel work as a deliberate risk mitigator against hiring a video editor. It does not unlock paid spend or redefine Phase 1 exit criteria.

**Why:** Phase 1 owns conversion existence; Studio owns creative production risk (freelanceCreative budget / future hire). Parallelism is intentional but must stay timeboxed (~20–30% maker time) with a kill rule after three Studio-assisted weeks if standard ≤60s cuts still need an external editor.

**Rejected:** Waiting until Phase 2 to start any studio system (leaves only loose scripts). Pausing Phase 1 to build a full CapCut clone.
