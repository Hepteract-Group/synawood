# Format entry

How operators pick a Studio format.

| Format | Entry |
|---|---|
| Video Suite | Studio → New project → Video Suite. Footage cut (clips on MAIN). |
| Motion ad | Studio → New project → Motion ad. Agent-authored Remotion in the Player. Chat footer **Craft** can switch Footage ↔ Motion graphics on an existing Video Suite / Motion ad project. |
| Instagram Carousel / Vertical Slideshow | Studio → New project → slideshow formats |
| Campaign Pack | Studio → New project → Campaign Pack, or **Campaigns** sidebar (`/campaigns`) |

URL or PDF extract is a **Start from** choice on the same Create Project modal — not a second New button.

Do not create Campaign Packs from the Slideshow entry path.
