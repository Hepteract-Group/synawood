# UX principles

1. **Founder-in-the-loop** — the Studio Agent drafts and cuts; humans Approve. Never auto-publish.
2. **One job per screen region** — chat instructs; timeline orients **and** edits (direct manipulation is a co-equal input, ADR-0016); player verifies; review actions commit.
3. **Cadence over craft** — imperfect weekly shipping beats perfect idle projects (matches founder content Runbook).
4. **Plain English always** — errors and statuses readable by a marketing hire, not an engineer.
5. **Product context is ambient** — voice/brand load from Product context; user should not paste ICP into every chat.
6. **Progress is visible** — Draft pack and Render Job state never hide in logs.
