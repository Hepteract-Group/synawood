# UX non-goals (v1)

- Real-time collaborative multiplayer editing (team is Product membership, not a shared cursor — ADR-0070)
- Mobile-native editor
- Frame-accurate pro keyframe UI as the **required** way to get an ad (chat-authored Remotion is the motion path — ADR-0091)
- CapCut / Premiere / After Effects **project file** import as the Studio document
- Unsandboxed model TSX; agent-written GLSL shaders (kit/Skia primitives instead)
- Random GIPHY/GIF stickers without a license (licensed Lottie as motion assets is in)
- Autoposting from Approve
- Hosted “unlimited” video, seat-only infinite generation, or Veo on a free trial (ADR-0082)
- Dumping Vercel’s full Gateway catalog into the picker (ADR-0084)
- Cursor-style writable filesystem in Studio (ADR-0086)
- Replacing the team’s recording session with a synthetic avatar
- Eye Contact / green screen / Rooms / rewrite-what-was-said / Premiere XML (see [editor-agents.md](../competitive/editor-agents.md))
