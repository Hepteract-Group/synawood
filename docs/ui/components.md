# Component patterns

## Prefer

- Clear primary button for Approve
- Destructive styling for Kill
- Inline status chips using shared vocabulary (`drafting`, `rendering`, …)
- Monospace for project ids, job ids, week ids
- Empty states that point to the next Runbook step

## Avoid

- Rounded-full pill forests
- Multi-layer neon shadows
- Emoji as status
- Dashboard-stat strips inside Studio
- Modal mazes for export — use inline job status
