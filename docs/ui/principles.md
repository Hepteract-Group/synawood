# UI principles (dashboard)

Synawood UI is an **operator console** for GTM work. It should feel calm, dense enough for weekly work, and distinct from the private example's consumer marketing site.

1. **Clarity over spectacle** — no hero marketing layouts inside the dashboard.
2. **One composition per primary view** — Studio is one workspace, not a widget dashboard of cards.
3. **Typography with intent** — avoid default Inter/Roboto/Arial stacks; pick a readable UI sans + optional mono for ids/paths.
4. **Atmosphere without noise** — subtle surface differentiation (gradients/texture) on the shell; not purple glow clichés.
5. **Cards only for interaction containers** — pipeline slots and review panels may use contained surfaces; do not card-wrap everything.
6. **Brand of Synawood ≠ brand of the private example ads** — the private example Brand kit applies inside compositions/exports; dashboard chrome has its own restrained tokens.
